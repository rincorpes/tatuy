# Experiments

Experiments deliberately test Tatuy under less controlled conditions. They are evidence, not necessarily recommended minimal architecture.

## Public showcase status

| Experiment | Browser status | Notes |
| --- | --- | --- |
| `001_breakout` | Excluded from V0 | Historical Breakout/Shatterphase prototype. |
| `002_entities` | Candidate | High-density pressure experiment reserved for browser performance measurement. |
| `003_procedural_fire` | Excluded from V0 | Placeholder until the experiment has meaningful behavior. |
| `004_test` | Excluded from V0 | Internal scratch sandbox. |
| `005_procedural_tree` | Playable | Seeded procedural growth with regeneration, pause, foliage, and depth controls. |
| `006_tree_explorer` | Candidate | Tracked for a later browser migration pass. |
| `007_infection_arena` | Playable | Shatterphase ecology laboratory with pointer aiming and keyboard controls. |

Procedural Tree controls: `R` new seed, `SPACE` regrow, `P` pause, `L` foliage, and arrow keys adjust depth.

Infection Arena controls: mouse aims; `SPACE` launches; `C` recalls; `F` releases a fungal spore; `P` pauses; `N` single-steps; `R` resets; `T`/`Y` toggle reproduction/seeding; `B`/`G`/`M`/`X` edit the tile under the pointer.

The `002_entities copy` directory is a local historical copy and is explicitly not a canonical showcase target.
