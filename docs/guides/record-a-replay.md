# Record a Replay

Enable replay settings for the game.

Use the default replay controls:

```text
F3 start recording
F4 stop recording
F5 playback
F6 stop playback
```

For useful deterministic replay:

- use a known initial scene
- use a consistent seed
- avoid uncontrolled external state
- preserve relevant game options

Replay stores simulation/input information, not video frames.
