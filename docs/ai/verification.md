# Verification

Before presenting a Tatuy code change:

## Verify

- import paths
- API signatures
- system phase
- system order
- resource availability
- lifecycle timing
- built-in activation
- scene configuration timing

## Tests

Identify the narrowest relevant tests.

Do not claim tests were executed unless a tool or the user confirms execution.

## Examples

Find the nearest fundamental example.

Use experiments for architecture pressure, not as unquestioned API guidance.

## Environment

Interactive examples require a desktop environment.

Video encoding requires FFmpeg.

## Documentation

If a public workflow changes, identify the documentation and example that should change with it.
