# AI Development Guide

Tatuy provides AI-oriented documentation to reduce blind repository exploration and make architectural constraints explicit.

Before proposing a change:

1. read `/AGENTS.md`
2. read [Architecture map](architecture-map.md)
3. read [Invariants](invariants.md)
4. inspect relevant canonical docs
5. inspect implementation
6. inspect a nearby example
7. identify relevant tests

Do not invent APIs because they would be convenient.

Verify current source.
